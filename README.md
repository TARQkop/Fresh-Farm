# \## ✨ Highlights

# 

# \- \*\*Mobile-first, premium feel\*\* — black / cream / orange identity, generous spacing, large touch targets.

# \- \*\*Product catalog\*\* with category filters, search and product detail pages.

# \- \*\*Order in one tap\*\* — call and WhatsApp buttons, plus a sticky action bar on phones.

# \- \*\*Slow, calm motion\*\* — CSS marquee belts, slide-in button fills, soft card lifts and an enter-only page transition.

# \- \*\*Accessible by default\*\* — `prefers-reduced-motion` respected everywhere, visible focus states, semantic markup.

# \- \*\*SEO-ready\*\* — metadata, `sitemap.xml` and `robots.txt` generated by Next.js.

# \- \*\*Zero backend\*\* — fully static export, hosted for free on GitHub Pages.

# ├── app/                  # Routes: home, products, products/\[slug], about, contact

# \## 🛠 Customize

# 

# | I want to change… | Edit |

# | --- | --- |

# | Business name, phone, WhatsApp, email, site URL | `lib/site.ts` (site URL can also come from `NEXT\_PUBLIC\_SITE\_URL`) |

# | Products and prices | `data/products.ts` |

# | Categories | `data/categories.ts` |

# | Images | `data/images.ts` and `public/images/` |

# | Colors, fonts, motion speeds | `app/globals.css` (`@theme` and the motion tokens) |

# \### Motion tokens

# 

# All animation timing lives in one place in `app/globals.css`:

# 

# ```css

# \--ease-lux:    cubic-bezier(.22, 1, .36, 1);

# \--dur-hover:   450ms;

# \--dur-reveal:  800ms;

# \--dur-page:    700ms;

# \--dur-marquee: 55s;

# ```

# \## 🌐 Deploy to GitHub Pages

# 

# The project uses `output: "export"` and `basePath: "/Fresh-Farm"` in `next.config.mjs`.

# 

# 1\. \*\*Rename `basePath`\*\* to match your repository name (or remove it if you use a custom domain or a `username.github.io` repo).

# 2\. Push the code to GitHub, then go to \*\*Settings → Pages → Source: GitHub Actions\*\*.

# 3\. Add `.github/workflows/deploy.yml`:

# 

# ```yaml

# name: Deploy to GitHub Pages

# on:

# &#x20; push:

# &#x20;   branches: \[main]

# permissions:

# &#x20; contents: read

# &#x20; pages: write

# &#x20; id-token: write

# concurrency:

# &#x20; group: pages

# &#x20; cancel-in-progress: true

# jobs:

# &#x20; build:

# &#x20;   runs-on: ubuntu-latest

# &#x20;   steps:

# &#x20;     - uses: actions/checkout@v4

# &#x20;     - uses: actions/setup-node@v4

# &#x20;       with: { node-version: 22, cache: npm }

# &#x20;     - run: npm ci

# &#x20;     - run: npm run build

# &#x20;       env:

# &#x20;         NEXT\_PUBLIC\_SITE\_URL: https://YOUR\_USERNAME.github.io/Fresh-Farm

# &#x20;     - uses: actions/upload-pages-artifact@v3

# &#x20;       with: { path: out }

# &#x20; deploy:

# &#x20;   needs: build

# &#x20;   runs-on: ubuntu-latest

# &#x20;   environment:

# &#x20;     name: github-pages

# &#x20;     url: ${{ steps.deployment.outputs.page\_url }}

# &#x20;   steps:

# &#x20;     - id: deployment

# &#x20;       uses: actions/deploy-pages@v4

# ```

# 

# > 💡 \*\*Local dev without the base path:\*\* set `basePath: process.env.NODE\_ENV === "production" ? "/Fresh-Farm" : ""` in `next.config.mjs`.

# \## ♿ Accessibility \& performance notes

# 

# \- Animations only use `transform` and `opacity`; no layout shift, no horizontal scroll.

# \- Hover effects apply only on real pointers (`hover: hover` and `pointer: fine`), so touch devices never get sticky hover.

# \- With `prefers-reduced-motion`, marquees stop (and become scrollable), transitions are instant and hover becomes a plain color change.

# \- Content is never hidden waiting for JavaScript.
